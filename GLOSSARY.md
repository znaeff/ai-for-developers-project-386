# Календарь звонков

Учебное приложение для бронирования встреч: владелец управляет календарём, гость выбирает свободное время и бронирует встречу.

## Language

**Владелец**:
Администратор календаря, который создаёт типы встреч и просматривает встречи, забронированные гостями.
_Avoid_: Администратор

**Гость**:
Пользователь календаря, который бронирует встречу в свободный слот, указывая своё имя и почту.
_Avoid_: Пользователь, посетитель

**Тип встречи**:
Шаблон встречи, который создаёт Владелец: название, описание и длительность в минутах. Гость выбирает Тип встречи при бронировании.
_Avoid_: Тип события, формат встречи
